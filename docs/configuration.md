# Configuration

VillagerAgent has two common configuration layers: Minecraft run configs and LLM provider configs.

## Minecraft Run Config

Minecraft benchmark configs are JSON files. They may be a single object or a list of objects. `benchmarks.minecraft.experiment` selects one object with `--config-index`.

Example:

```json
[
  {
    "task_type": "meta",
    "task_idx": 0,
    "agent_num": 1,
    "max_task_num": 1,
    "task_goal": "Inspect the immediate area and report one safe next step.",
    "document_file": "",
    "host": "10.12.3.1",
    "port": 40000,
    "task_name": "minecraft_smoke",
    "role": "same",
    "evaluation_arg": {}
  }
]
```

Fields:

- `task_type`: environment/judger type. Current runtime branches include `construction`, `farming`, `puzzle`, `meta`, and `gen`.
- `task_idx`: task index passed to `VillagerBench` and the judger.
- `agent_num`: number of agents to register.
- `max_task_num`: maximum task count passed into the environment.
- `task_goal`: top-level natural-language goal for `TaskManager.init_task()`.
- `document_file`: optional JSON document loaded into task metadata when the file exists.
- `host`: Minecraft server host.
- `port`: Minecraft server port.
- `task_name`: run name used for cache, result, and artifact paths.
- `role`: role layout selector. `same` uses the same tool set for all agents; some `farming` runs support `different`.
- `evaluation_arg`: metadata passed into `document` for `meta` tasks.
- `dig_needed`: optional flag for construction tasks.
- `smoke_tasks`: optional dry-run fixture tasks used by benchmark tests and matrix runs.
- `smoke_action_log`: optional dry-run fixture action log.

## LLM Defaults

The default LLM configuration is generated by `model/ollama_config.py`:

```json
{
  "provider": "ollama",
  "api_key": "ollama",
  "api_base": "http://localhost:11434/v1",
  "api_model": "gemma4:12b",
  "api_key_list": ["ollama"]
}
```

Environment variables override the defaults:

- `OLLAMA_API_BASE`: defaults to `http://localhost:11434/v1`.
- `OLLAMA_MODEL`: defaults to `gemma4:12b`.
- `OLLAMA_API_KEY`: defaults to `ollama`.

`API_KEY_LIST` remains supported for legacy or paid providers. The expected legacy shape is:

```json
{
  "AGENT_KEY": ["key-a", "key-b"]
}
```

For Ollama, the file is optional. Missing or empty keys fall back to `[OLLAMA_API_KEY]`.

## CRAFT Configs

CRAFT evaluation configs are YAML files under `configs/craft/`. They have separate `run`, `craft`, `villageragent`, `models`, and `logging` sections. Some files intentionally name specific comparison models such as `qwen3.5:9b` or `gemma4:e4b`; those are experiment-specific and do not change the repository-wide Ollama default.

## Benchmark CLI Options

Single Minecraft benchmark:

```bash
python -m benchmarks.minecraft.experiment \
  --config configs/minecraft/experiments/issue110_smoke.json \
  --output-root result/minecraft \
  --run-name local_smoke \
  --config-index 0 \
  --dual-dag-task-selection
```

Add `--execute` to mutate the real environment. Add `--execute-timeout-seconds N` to bound real runs and preserve artifacts on timeout.

Matrix dry-run:

```bash
python -m benchmarks.minecraft.matrix \
  --config configs/minecraft/experiments/issue107_smoke_comparison.json \
  --output-dir result/minecraft_matrix \
  --run-names run_a,run_b \
  --dual-dag-task-selection
```
